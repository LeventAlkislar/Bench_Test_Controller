**Mimari**
Proje bir PyQt6 masaüstü uygulaması. Ana akış şöyle:

`UI -> Recipe/Session akışı -> Valve + DropView kontrolü -> Measurement veri/log işleme -> Viewer/Log ekranları`

Katmanlar:
- `bench_test/ui/`: Kullanıcı arayüzü.
- `bench_test/recipe/`: Test adımlarını/senaryoları koordine eder.
- `bench_test/valve/`: Donanım valf haberleşmesi.
- `bench_test/dropview/`: DropView yazılımını GUI otomasyonu ile sürer.
- `bench_test/measurement/`: Session, log, paketleme, veri okuma ve agregasyon.
- `bench_test/utils/`: Yol ve debug yardımcıları.
- `bench_test/config.py`: Sabitler.
- `bench_test/version.py`: Uygulama adı/sürümü ve pencere başlığı üretimi.

**Kök Dizin**
- `main.py`: Uygulamayı başlatır, hata loglamasını kurar, uygulama ikonunu yükler, `MainWindow` açar.
- `bench_test/`: Asıl kaynak kod.
- `ui/`: Ekran görüntüsü / referans görseller.
- `build/`: PyInstaller build ara çıktıları.
- `dist/`: Üretilmiş `.exe` sürümleri.
- `.venv/`: Sanal ortam.
- `.idea/`: IDE ayarları.
- `bench_test_debug.log`: Debug log dosyası.
- `BenchTestController*.spec`: Farklı release sürümleri için PyInstaller spec dosyaları.
- `build_release.ps1`: Release/build otomasyonu.
- `AGENTS.md`, `SKILL.md`, `*.md`: İç dokümantasyon ve notlar.
- `Project File Organization.txt`: Proje organizasyon özeti.

**Dosyalar ve İşlevleri**

`bench_test/config.py`
- Timeout, polling, pencere adları, COM portlar, eşik değerleri, varsayılan script parametreleri gibi global sabitleri tutar.

`bench_test/version.py`
- Uygulama adı ve sürüm bilgisini tanımlar.
- Pencere başlığı metnini üretir.

**UI katmanı: `bench_test/ui/`**
- `main_window.py`: Ana pencereyi kurar; `Manual Control`, `Measurement Setup`, `Recipe Control`, `Graphics Viewer`, `Full Log` sekmelerini bağlar. Session context, banner’lar ve sekmeler arası senkronizasyon burada yönetilir.
- `widgets.py`: Ortak UI yardımcıları.

`bench_test/ui/assets/`
- `app_icon.ico`, `app_logo.png`: Uygulama ikon ve logo dosyaları.

`bench_test/ui/tabs/`
- `connection_tab.py`: Şu an çok küçük; bağlantı sekmesi için yer tutucu/kalıntı dosya gibi duruyor.
- `log_tab.py`: Session loglarını ve çalışma loglarını gösterir.
- `manual_tab.py`: Valfler ve DropView üzerinde manuel operasyonlar.
- `measurement_setup_tab.py`: Ölçüm kurulumu; package/method/script alt panellerini birleştirir.
- `method_editor_panel.py`: Method dosyası/parametreleriyle ilgili düzenleme veya görüntüleme paneli.
- `package_panel.py`: Session oluşturma, klasör/dosya yapısı, paketleme ve temizleme akışı.
- `recipe_tab.py`: Recipe oluşturma, yükleme, çalıştırma, durdurma ve durum takibi.
- `script_params_panel.py`: Script üretiminde kullanılan parametreler.
- `viewer_tab.py`: Session verilerini, grafikleri ve geçmiş oturumları gösterir.

**Recipe katmanı: `bench_test/recipe/`**
- `models.py`: Recipe veri modelleri.
- `runner.py`: Recipe adımlarını sıralı şekilde yürütür; valf ve DropView işlemlerini tetikler.

**Valve katmanı: `bench_test/valve/`**
- `protocol.py`: Cihaz haberleşme protokolü.
- `base_controller.py`: Ortak valf kontrol tabanı.
- `multiport.py`: Multiport valf sürücüsü.
- `injector.py`: Injector valf sürücüsü.

**DropView entegrasyonu: `bench_test/dropview/`**
- `controller.py`: UI ile DropView otomasyon katmanı arasındaki köprü.
- `automator.py`: DropView penceresinde buton tıklama, script yükleme, run/stop gibi otomasyon adımlarını yürütür.
- `script_generator.py`: DropView script içeriği üretir.
- `vision.py`: Ekran görüntüsü alma ve template matching yardımcıları.
- `window_actions.py`: Pencere öne alma, güvenli tıklama, hotkey gönderme, odak yönetimi gibi düşük seviye Windows UI aksiyonları.
- `img/`: Aktif kullanılan referans otomasyon görselleri.
- `img unused/`: Kullanılmayan/eski görseller.

**Measurement katmanı: `bench_test/measurement/`**
- `aggregator.py`: Ölçüm çıktılarının birleştirilmesi/toplanması.
- `data_io.py`: CSV/XLSX okuma katmanı; viewer ve aggregation için ortak veri erişimi sağlar.
- `legacy_session.py`: Eski session formatlarıyla uyumluluk için yardımcı model/okuma mantığı.
- `log_parser.py`: Session loglarını parse eder.
- `log_writer.py`: Çalışma sırasında log satırları yazar.
- `packager.py`: Session klasör yapısı ve çıktı dosyalarının paketlenmesi.
- `session.py`: Güncel measurement session modeli ve yükleme/kaydetme.
- `session_context.py`: Uygulamanın o anda hangi session’ı hangi modda gösterdiğini tutar.
- `state_machine.py`: Session yaşam döngüsü ve ölçüm durum geçişleri.

**Utils katmanı: `bench_test/utils/`**
- `paths.py`: Yol yardımcıları, başlangıç dizinleri, dosya seçim akışları.
- `debug_log.py`: Ayrı debug logger kurar ve `bench_test_debug.log` dosyasına yazar.
- `last_paths.json`: Son kullanılan yolların kalıcı kaydı.

**Kaynak Dışı Ama Projeye Ait**
- `ui/*.png`: Sekme ekran görüntüleri.
- `dist/*.exe`: Release binary’leri.
- `build/BenchTestController/`: Paketleme/build çıktıları.

**Özet**
Güncel durumda proje:
- bir PyQt6 arayüzü,
- recipe tabanlı test akışı,
- valf donanımı kontrolü,
- DropView GUI otomasyonu,
- session/log/veri işleme ve grafik gösterimi

  ↓
